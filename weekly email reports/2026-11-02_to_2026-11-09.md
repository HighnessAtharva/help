# Weekly Help Documentation Updates

**Period covered:** 2026-11-02 to 2026-11-09
**Subject line used:** Weekly Help Documentation Updates (Last 7 Days)

## Overview

This week AccuKnox published 5 new pages in two areas. BlueLock is a new runtime security guide set for serverless containers, with an overview and three deployment guides. Agent Identities is a new guide for securing coding agents such as Claude Code and Codex. The Shadow AI Discovery page was rewritten and now lists all 50 supported AI tools with their logos. The integrations pages and the AI/ML support matrix were updated to match.

## New Documentation

**BlueLock Runtime Security for Serverless Containers**
URL: https://help.accuknox.com/how-to/bluelock/

BlueLock is the AccuKnox open-source engine for runtime security where you cannot reach the host, such as AWS Fargate and Azure Container Apps. It runs inside the workload and enforces KubeArmor policy. The page has a four-step diagram of how enforcement works and cards that link to each environment guide. Send it to any customer who runs containers on a serverless platform.

**Deploy BlueLock on EKS Fargate**
URL: https://help.accuknox.com/how-to/bluelock-eks-fargate/

This guide takes you from a new EKS Fargate cluster to a working block policy in six steps. You deploy the relay and a sample workload, onboard the cluster to AccuKnox, and block `apt` in the sample pod to prove enforcement. Use it for Fargate proofs of concept.

**Deploy BlueLock on ECS Fargate**
URL: https://help.accuknox.com/how-to/bluelock-ecs-fargate/

This guide covers ECS Fargate with screenshots for each console step. It shows the IAM role and policy, the join token, the task run, and the alerts that appear when a command is denied. Use it for customers who run Fargate without Kubernetes.

**Deploy BlueLock on Azure Container Apps**
URL: https://help.accuknox.com/how-to/bluelock-azure-container-apps/

This guide builds an Azure Container Apps test environment with Terraform. You onboard the replicas to AccuKnox as a VM cluster and block a command in a running replica. Use it for Azure customers who run serverless containers.

**Secure Coding Agents With Agent Identities**
URL: https://help.accuknox.com/how-to/agent-identities/

Coding agents run with the developer's own login, so their calls look like the developer's calls. This guide gives each agent its own name, an approved list of models, a trace of its activity and access you can revoke. It covers Claude Code and Codex in five steps, with a walkthrough video. Send it to security teams that ask how to govern coding agents.

## Updated Documentation

**Shadow AI Discovery**
URL: https://help.accuknox.com/use-cases/shadow-ai-discovery/

The page was rewritten. It now covers endpoints and VMs on Linux, Windows and macOS, Kubernetes, cloud accounts and the browser. A new matrix lists all 50 supported AI tools with logos. The page says that discovery confirms a tool is installed, not that anyone uses it.

**Integrations and AI/ML Support Matrix**
URL: https://help.accuknox.com/integrations/support-matrix/

The integrations pages and the AI/ML support matrix now show the same tool logos as the Shadow AI page. Customers can scan which AI tools AccuKnox supports at a glance.

**AccuKnox v3.7 Release Notes**

The release notes were adjusted to match the Shadow AI changes.
